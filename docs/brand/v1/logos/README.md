# Kit Vetorial do Ecossistema Numera

Conjunto oficial de marcas vetoriais da família `Numera`, compartilhando o grid `64x64`, desenho em curvas contínuas sem cantos de 90 graus, escala acromática em dois níveis (`100%` e `36%`) e tipografia `Figtree 600` (`letter-spacing: -0.03em`).

## Convenções de Uso

1. Os símbolos `*-mark.svg` usam `currentColor` com `color="#0A0A09"` por padrão para herança direta quando embutidos em HTML/React ou colorização simples em editores vetoriais.
2. Os lockups `*-lockup-dark.svg` destinam-se a fundos escuros (`#0A0A09` / `#141412`), e `*-lockup-light.svg` a fundos claros (`#F4F3EF` / `#FAF9F6`).
3. Apenas `NYOT` permanece integralmente em caixa alta por se tratar de sigla. `Numera`, `Monno` e `Cronos` usam sempre Title Case.
4. O endosso `Um app Numera` utiliza `Figtree 500`, sem monospace.
5. Para uso direto em ferramentas que não possuam a fonte `Figtree` instalada localmente, converta os textos em curvas no editor vetorial após abrir o arquivo ou instale `Figtree` (`300/400/500/600`).
